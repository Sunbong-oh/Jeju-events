# 제주 행사 알리미

**4~6살 아이와 갈 만한 제주 행사**를 골라, 집에서의 거리와 함께 정리합니다. 음악 공연은 우선 추천합니다.

다음 출처에서 행사의 **신청기간**과 **행사일**을 매일 모아 웹페이지에 정리하고, 해당 날짜에 텔레그램으로 알림을 보냅니다.
- 제주도(`jejudo_official`), 제주시(`wowjejusi`), 서귀포시(`seogwipo-si`) 네이버 블로그: 글 본문에서 날짜를 자동으로 찾습니다.
- 제주교육청 통합예약시스템(org.jje.go.kr/reserve)의 견학/체험, 교육/강좌, 공연/행사 목록: 운영기간과 접수기간(마감 시각 포함)을 그대로 가져옵니다. 접수 상태가 바뀌면 매일 갱신합니다.
- 제주관광협회(visitjeju.or.kr) 행사안내 게시판: 매주 올라오는 월별 '축제 행사 일정' 첨부파일(hwpx)의 표에서 축제명, 일정, 장소를 가져옵니다. 신청 기간이 없는 축제이므로 행사 시작 하루 전과 당일에 알림이 갑니다.
- 네이버 블로그 검색: 이번 달과 다음 달의 "N월 제주행사" 검색 결과에 나온 블로그 글을 함께 읽습니다. 설정은 config의 naver_search에서 검색어와 개월 수를 바꿉니다. 블로그 글은 날짜를 추정하므로 원문 링크로 꼭 확인하세요.

## 1. 텔레그램 봇 만들기 (최초 1회)
1. 텔레그램에서 `@BotFather`를 찾아 `/newbot`을 보내고, 안내에 따라 봇을 만듭니다. 마지막에 **토큰**(`123456:ABC...`)을 받습니다.
2. `config.example.json`을 복사해 `config.json`을 만들고, `telegram_bot_token`에 토큰을 넣습니다.
3. 방금 만든 봇과의 대화창을 열어 아무 메시지나 보냅니다.
4. `python get_chat_id.py`를 실행해 나온 숫자를 `telegram_chat_id`에 넣습니다.

## 2. 웹페이지
`start_web.bat`을 더블클릭하면 http://127.0.0.1:8765 가 열립니다.
- **다가오는 일정**: 남은 날짜 순으로 정렬되고, D-day가 표시됩니다.
- **날짜 확인 필요**: 날짜를 자동으로 찾지 못한 글입니다(이미지로만 된 글 등). 원문을 보고 날짜를 직접 입력하면 바로 저장됩니다.
- 잘못 추출된 날짜는 수정하면 되고, 필요 없는 항목은 '숨기기'를 누르면 됩니다.

## 3. 매일 자동 실행 (Windows 작업 스케줄러)
`run_daily.bat`이 하는 일: 새 글 수집 → 알림 전송 → `data/run.log`에 기록.

알림을 보내는 경우는 다음과 같습니다.
| 언제 | 알림 |
|---|---|
| 새 행사가 수집됐을 때 | 🆕 새 행사 목록 |
| 신청 시작일 | 📝 신청 시작 (오늘) |
| 신청 마감 하루 전 / 당일 | ⏰ 신청 마감 D-1 / (오늘) |
| 행사 하루 전 / 당일 | 🎉 행사 시작 D-1 / (오늘) |

그날의 알림은 메시지 하나(길면 몇 개)로 묶어서 보냅니다. 며칠 전에 미리 알릴지는 `remind_days_before`로 정합니다(0이면 당일만). 같은 알림은 두 번 보내지 않습니다.

## 블로그·수집 범위 바꾸기
`config.json`의 `blogs`를 수정합니다. `keywords` 중 하나라도 글의 카테고리나 제목에 들어 있으면 수집하고, 빈 목록이면 모든 글을 수집합니다.
네이버 RSS에는 최근 글 약 50개만 나오므로, PC가 며칠 꺼져 있어도 그 사이 글은 대부분 수집됩니다.

### 교육청 예약 범위 바꾸기
`config.json`의 `reserve` 항목에서 설정합니다.
- `categories`: 견학/체험, 교육/강좌, 공연/행사, 시설대관 중 원하는 분류
- `targets_any`: 대상에 이 단어가 하나라도 있는 것만 수집 (예: `["학부모", "가족", "일반"]`). 교직원이나 기관 전용 프로그램을 빼고 싶을 때 씁니다.
- `max_pages`: 분류마다 최대 몇 쪽(쪽당 10개)까지 볼지. 한 쪽의 프로그램이 모두 한 달 넘게 지났으면 그 앞에서 멈춥니다. 도서관의 학기 단위 프로그램처럼 일찍 등록된 것도 놓치지 않도록 넉넉하게 잡았습니다.
- 웹페이지에서 날짜를 직접 고친 항목은 자동 갱신 때 덮어쓰지 않습니다.

## 아이 맞춤 판정
행사마다 ⭐ 추천 / 가능 / 제외 중 하나로 판정합니다 ([kidfit.py](kidfit.py)).
- **⭐ 추천**: 유아·가족·어린이·그림책·놀이 등이 들어간 행사, 대상이 '유아·가족'인 교육청 프로그램, 나이 조건이 4~6세와 겹치는 행사, 좋아하는 종류(🎵 음악회·공연·버스킹 등)
- **가능**: 축제·장터·전시처럼 누구나 갈 수 있는 행사
- **제외**: 성인·중고등학생·교직원 대상, 아이 대상 표시가 없는 외국어·학습 과정, 나이 조건이 맞지 않는 행사
- 판정이 틀리면 웹페이지의 '⭐ 추천으로' 또는 '아이랑 안 맞음' 버튼으로 바로잡을 수 있습니다.
- 텔레그램 알림은 추천과 가능만 보냅니다. '가능' 행사는 집에서 `notify_max_km`(기본 25km)보다 멀면 알림에서 뺍니다.
- `config.json`의 `child`에서 나이(`age_min`, `age_max`)와 좋아하는 종류(`likes`)를 바꿀 수 있습니다.

## 거리 표시
지도 API 없이 장소 글귀에 나온 읍·면·동 이름과 주요 장소(탐라문화광장, 용연, 함덕, 돌문화공원 등)로 위치를 추정합니다([geo.py](geo.py)). 집에서의 **직선거리**라서 ±2~3km 정도 오차가 있습니다.
장소를 알 수 없으면 거리를 표시하지 않습니다. 집 위치는 `config.json`의 `home`에서 바꿀 수 있습니다.

## GitHub에서 자동 실행 (PC가 꺼져 있어도 동작)
`.github/workflows/daily.yml`이 매일 한국 시간 오전 8시에 수집, 알림, 사이트 생성을 하고, 결과(`data/events.json`, `docs/`)를 저장소에 저장합니다.

**처음 한 번 설정하기**
1. GitHub에서 새 저장소를 만들고 이 폴더를 올립니다.
2. 저장소의 Settings → Secrets and variables → Actions → New repository secret에서 아래 값을 등록합니다.
   - `TELEGRAM_BOT_TOKEN`: 봇 토큰
   - `TELEGRAM_CHAT_ID`: 채팅 ID
   - `HOME_LAT`, `HOME_LNG`: 집 위도·경도. 텔레그램 알림의 거리 계산에만 쓰고, 공개 웹페이지에는 나오지 않습니다.
3. Actions 탭 → `daily` → **Run workflow**로 첫 실행을 합니다.
4. Settings → Pages에서 Source를 `Deploy from a branch`, Branch를 `main`, 폴더를 `/docs`로 정하면 `https://아이디.github.io/저장소이름/`에 웹페이지가 열립니다.

**웹페이지는 보기 전용입니다.** 고치고 싶은 항목은 카드 아래에 있는 ID를 복사해, GitHub에서 `overrides.json`을 다음처럼 수정하면 됩니다. 다음 실행 때 반영됩니다.
```json
{
  "jje-ED_0000000003950": {"fit_override": "no"},
  "vj-2026제주야페스타-2026-10-30": {"fit_override": "good"},
  "wowjejusi-223456789-0": {"event_start": "2026-11-08", "event_end": "2026-11-09"},
  "jje-EX_0000000000676": {"hidden": true}
}
```

설정(나이, 좋아하는 종류, 블로그 목록 등)을 바꾸려면 `settings.json`을 만들어 `config.example.json`과 같은 형식으로 바꿀 항목만 적으면 됩니다. 토큰이나 집 위치는 여기에 적지 말고 Secrets에만 넣으세요.

참고: 저장소에 60일 동안 아무 활동이 없으면 GitHub가 예약 실행을 멈춥니다. 매일 실행 결과가 저장되면서 활동으로 잡히므로 보통은 문제없습니다.
